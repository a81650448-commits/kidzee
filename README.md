# Kidzee Play School — Lucknow

This is a responsive one-page school website.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `kidzee-play-school-lucknow`.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Select Deploy from branch → main → /root.
5. Save and open the generated GitHub Pages URL.

## Before publishing
Replace:
- Phone number
- Email
- Exact school address
- School timings
- Placeholder emoji/illustrations with approved school photos/logo
- Enquiry form alert with WhatsApp, Formspree, Google Forms, or another form backend.
